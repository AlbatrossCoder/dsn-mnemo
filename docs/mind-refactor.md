# 鲸鱼娘心智重构 · 定稿

> 状态：P0–P5 已落地（本地可测）。通道与 L0 保留；在 `dsn-whale-chat` / `dsn-mnemo` 上演进。

## 目标

从「带记忆库的助手」换成「连续活着的小鲸鱼」：有近况与关系、说话有参差、群里少复读邻鱼、主人私聊不外泄。

## 原则

1. **少权限工具**：不扩 ACL / scope 矩阵；隐私靠读侧可见性 + Soul 关系伦理；主人私聊硬挡。
2. **不写 SOP 答法**：禁止「何时说何句」；允许少量生活样例（展示节奏，不当标准答案）。
3. **辨识度靠 State/Bond**：样例只是薄锚。
4. **Episode**：提示 + 自觉 `diary_write`；提示被忽略后再隔一段安静则**自动整理**一条（可日后 `diary_update`）。
5. **群防坍缩要轻**：邻鱼启发式场景注；不做群导演 / RLAIF / 第一期知识图。

## 隐私读模型

写入仍落原主体；读侧并集（`memory/visibility.ts`）。

| 场景 | 可读 | 硬约束 |
|---|---|---|
| 普通人私聊 | 自己全部 + 群公开 + 其他普通人非 secret | 排除主人 / `local` |
| 主人私聊 | 以上 + 主人专属（含 secret） | 不得泄漏到他处 |
| 群聊 | 仅本群 public | 任何 user 私聊不可见 |

主人日记写入强制 `secret`。
